A spellbook invocation selects a protocol. It does not silently expand that protocol's authority.

```text

REQUEST != RECEIPT

```

## Compatibility

The spellbook is a user-facing registry, not a replacement for the underlying canonical contracts. Existing command files and protocols remain authoritative for their own behavior.

New spellbook entries require explicit Naomi authorization.
