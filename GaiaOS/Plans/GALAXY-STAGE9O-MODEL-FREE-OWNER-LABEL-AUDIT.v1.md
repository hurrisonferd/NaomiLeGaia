## Aggregate output and proof boundaries
Counts: owner-labeled current cases (3), attested negative controls (2), owner single-source/collision/unknown strata, categorical agreements/disagreements, single-source grounded agreements, collision claims that agree but remain semantically unverified, missed owner collisions, and owner-vs-generator oracle support. All numbers derive only from already signed/validated finite receipts; raw questions, statements, record identifiers, source IDs, quote text, bearer token and HMAC key are never reflected. Malformed or unverifiable comparisons do not produce an audit.

`model_called_now=false` means the comparison makes **no fresh call**; the input signed model receipt records an *earlier* owner-authorized call. Source readback is NOT semantic entailment. A model COLLISION answer agreeing with the owner is not a verified A+B meaning check. One sample cannot prove general accuracy or independently representative query coverage. An owner support set is not permission to manufacture technical SUPERSEDES. Historical retrieval, Turso restart parity, general semantic quality and BIGBANG remain separate locked gates.
