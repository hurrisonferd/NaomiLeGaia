## What ConvoOS is

ConvoOS owns typed current conversation state and continuity semantics — working memory for the active context, not the full history authority. ChatOS consumes bounded current ConvoOS consequence when material. It does not become conversation-history authority or identity owner.

```text
CONVOOS != CONVERSATION HISTORY AUTHORITY
CONVOOS != IDENTITY OWNER
CONVOOS != CHATOS
```

RavenOS ConvoOS proved the pattern. GaiaOS ports the contract pointer — no Raven continuity state, no Raven autobiographical memory, no Raven identity store.
