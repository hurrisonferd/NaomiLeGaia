# GaiaOS YggdrasilOS

```text
AUTHORITY: NAOMI
OWNER: YggdrasilOS
STATUS: ACTIVE SOURCE / READ-ONLY RELATIONSHIP GRAPH
IDENTITY EFFECT: NONE
```

YggdrasilOS is GaiaOS's relationship map. DictionaryOS answers **what object might Naomi mean?** YggdrasilOS answers **what is that object connected to, and which source paths make the connection useful?**

```text
DICTIONARYOS OBJECT CANDIDATES
→ CURRENT GAIA GRAPH NODES
→ BOUNDED EDGE TRAVERSAL
→ RELATED OBJECTS + RELATION TYPES + SOURCE PATHS
→ BRAINOS CONTEXT COMPASS MAY SELECT THE SMALLEST USEFUL PACK
```

It is deliberately not a magic omniscience layer. The graph contains only explicit Gaia-native nodes and relationships. A missing edge remains unknown rather than becoming inference-shaped furniture.

## Boundary

RavenOS donated the separation between semantic naming and graph traversal. GaiaOS owns this graph and its node IDs. Raven ownership, private continuity, and identity do not cross the port.

```text
GRAPH HIT != AUTHORITY
EDGE != EFFECT
DISCOVERY != SETTLEMENT
ARCHITECTURE DONOR != IDENTITY DONOR
NAOMI SETTLES
```
