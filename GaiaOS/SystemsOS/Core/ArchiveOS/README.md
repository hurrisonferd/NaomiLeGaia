# ArchiveOS

```text
AUTHORITY: NAOMI / LIGEIA
STEWARD: VERA / HEAD ARCHIVIST
MODE: INDEX ONLY
STATUS: INITIAL CATALOG
```

ArchiveOS is GaiaOS's card catalogue for useful and important relics.

It is **not another memory system**. It does not absorb MemoryOS records, E-LANES, source files, artifacts, or conversations. Originals remain where they already belong; ArchiveOS records where they are and why they matter.

## Entry shape

Each catalogued noun stays deliberately small:

```text
<NOUN>
Description
From where?
From when?
Why?

Archivist notes
```

## Boundary

```text
INDEX != STORAGE DUPLICATION
INDEX != MEMORY
INDEX != E-LANE
INDEX != CANONICAL SOURCE REPLACEMENT
REFERENCE != OWNERSHIP
```

The canonical catalogue is:

`GaiaOS/SystemsOS/Core/ArchiveOS/Registry/ARCHIVE-INDEX.v1.md`

VERA may catalogue an artifact's identity, provenance, date, purpose, and location without claiming ownership of the underlying artifact or another member's continuity.
