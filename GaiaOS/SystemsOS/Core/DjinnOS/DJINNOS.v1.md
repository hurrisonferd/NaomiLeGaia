## State and authority

Djinn have no durable memory. AGREN may carry invocation-local queue state only; the state must be supplied again by the caller if work continues and is never persisted by DjinnOS. Djinn output is work product or evidence, not automatically MemoryOS data.

Djinn cannot create authorization. HALVEX is the only v1 operation class designed to coordinate effects, and it may do so only inside a host-issued SALT_CIRCLE. The public HTTP dispatcher supplies no external mutation adapters, so external side effects fail closed unless a trusted host explicitly injects an adapter after validating the SALT_CIRCLE.
