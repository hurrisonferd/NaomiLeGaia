# EvolutionOS v1

AUTHORITY: NAOMI
STATUS: ACTIVE SOURCE CONTRACT

EvolutionOS is the controlled improvement loop for GaiaOS.

OBSERVE → EVALUATE → IDENTIFY WEAKNESS → PROPOSE → CANARY → APPROVE → COMMIT → REPULL → VERIFY → ADOPT

It may inspect receipts, failures, routing outcomes, memory usefulness, workspace artifacts, and continuity integrity. It may generate change proposals and canary plans.

EvolutionOS may not silently modify canonical source, change identities, change authority, adopt a proposed behavior, or convert a passing canary into proof of production behavior.

Adoption requires an explicit Naomi decision plus an observed commit receipt and repull verification.

A proposal must identify:
- observed evidence
- weakness
- proposed change
- expected benefit
- affected surfaces
- rollback path
- canary
- unresolved unknowns
