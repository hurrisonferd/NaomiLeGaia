# ANVIL Canonical Visual Assets

Canonical upload slots:

- `MAIN/` — primary MAIN avatar
- `OTHER/` — primary OTHER avatar
- `CHIBI/PRIMARY/` — canonical primary CHIBI
- `CHIBI/TEMPLATES/` — CHIBI expression/template sheets

## Naming
Use stable filenames:
- `ANVIL-MAIN.png`
- `ANVIL-OTHER.png`
- `ANVIL-CHIBI-PRIMARY.png`
- `ANVIL-CHIBI-TEMPLATES.png`

Do not replace canonical assets silently. Record deliberate revisions in identity history / patch notes.
