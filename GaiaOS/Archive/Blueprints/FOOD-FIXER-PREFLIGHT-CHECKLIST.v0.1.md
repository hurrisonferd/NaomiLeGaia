## Phase 0 — Basic equipment check (first task; low effort)

**Goal:** Determine if webcam and microphone work and find Acer hardware details.

- [ ] Locate webcam and any USB cable.
- [ ] Plug webcam into Acer.
- [ ] Open Windows **Camera**; confirm video feed.
- [ ] Record and replay a 20-second webcam clip; check video and microphone.
- [ ] Use Windows Task Manager → **Performance** and Settings → **System → About** to note CPU, GPU, RAM and Windows version.
- [ ] Check remaining storage capacity before recording video.
- [ ] Locate headphones/earbuds, microphone (built-in acceptable initially), and AC charger.
- [ ] Ensure adequate laptop ventilation/airflow.
- [ ] Make a very short spoken test without trying to be "camera-ready."

**PASS:** Webcam works or a specific webcam issue is identified; usable microphone/capture hardware established. **Stop here if tired.**

## Phase 1 — OBS local recording benchmark

**Goal:** Cyberpunk playable while recording clean video and intelligible commentary.

- [ ] Download OBS Studio from **https://obsproject.com/** if not already installed.
- [ ] Run OBS Auto-Configuration Wizard with recording as initial purpose.
- [ ] Create **FF - Gameplay Test** scene with Cyberpunk **Game Capture**.
- [ ] Add desktop/game audio and microphone, avoiding duplicate tracks.
- [ ] Use **1280×720, 30fps** as a starting test, not a guaranteed correct final setting.
- [ ] Try hardware encoder if compatible/stable; otherwise use the best practical alternative.
- [ ] Set recording folder to a location with room for captures.
- [ ] Prefer resilient recording format such as **MKV**; remux later if required for editing.
- [ ] Record five minutes of actual driving without webcam/overlays.
- [ ] Replay the file: does video stutter, audio desync, mic crackle, or capture go black?
- [ ] Assess whether the game itself remains enjoyable on Acer with OBS running.
- [ ] Add webcam for a **separate** test; keep it only if performance allows.
- [ ] Test any necessary game/display/window capture fallback if Game Capture fails.
- [ ] Keep the no-webcam working setup as a low-load fallback.
- [ ] Preserve a known-good OBS scene/recording profile.

**PASS:** Five minutes of watchable gameplay and voice. **Webcam is optional.**

- [ ] Apply one disclosed loan disbursement, purchase the car normally, and record debt independently from wage income.
- [ ] Use **€$20 per successful completed delivery** as Naomi's intended base pay.

- [ ] Test five-delivery refueling interval **provisionally**, including actual visit/parking at a gas station.
- [ ] Test **€$30 fuel** and **€$25 car installment** per five completed deliveries as provisional rates, not irrevocable contracts.
- [ ] Ensure each paid car installment reduces principal by exactly the amount truly settled.
- [ ] Record any missed payments honestly; do not invent wallet deductions.
- [ ] Distinguish story/quest earnings from simulated Food-Fixer wages.
- [ ] Check that low earnings make the €$10K apartment goal a **long-term** arc, not a falsely promised quick finale.
- [ ] Prove one full delivery → verified payroll entry → updated ledger.

**PASS:** One job's financial outcome is consistent in ledger and V's actual wallet; loan bookkeeping is coherent.

## Phase 4 — Sound and music rights (ADDED 2026-10-11)

**Goal:** Use Night City atmosphere and original Ableton music without avoidable copyright problems.

- [ ] In Cyberpunk **Settings → Sound/Audio**, enable **Disable Copyrighted Music → ON** before any footage intended for release.
- [ ] Verify that toggle is still enabled when reopening the game or loading the dedicated save.
- [ ] Audition the remaining radio stations under the filter: Vexelstrom/Ritual FM (aggressive), Radio PEBKAC/Impulse (techno), Pacific Dreams (mellow), Growl FM/The Dirge (variety). **Not a verified track-clearance list.**
- [ ] Choose whether recorded episodes have in-game radio, minimal ambiance, or an edited original soundtrack.
- [ ] Observe whether any Phantom Liberty tracks still play despite the toggle; CDPR specifically noted **"Delicate Weapon" by Grimes** as an exception.
- [ ] Build a **separate playlist/library** of original Food-Fixer music and any third-party tracks with suitable broadcast/VOD/video rights.
- [ ] **Do not** assume streaming Spotify or another consumer subscription's playlist is allowed.
- [ ] Use Ableton to make at least **one short order-received cue**; export a WAV.
- [ ] Optionally make app-startup, delivery-complete, failure, fuel-due, loan-due, ON SHIFT, OFF SHIFT and corporate-warning sounds.
- [ ] Use consistent file names (for example `FF_Order_Received.wav`); preserve original Ableton projects and final WAV files.
- [ ] Import a WAV into OBS **Media Source** and verify trigger, restart, playback routing, and volume.
- [ ] Check microphone speech remains clear and louder than notifications/music.
- [ ] For YouTube Episode One, consider adding most music **in editing** to conserve runtime processing.
- [ ] Perform an unlisted YouTube audio/claim review, and consider Twitch VOD muting/claim risks before public release.
- [ ] Document any licensed external music separately; original production and Cyberpunk gameplay audio have different permissions.

**PASS:** Creator music filter is set, one original cue is usable, and the draft episode has had an explicit copyright/audio review.

## Phase 6 — Stream Deck / free iPhone controller (ADDED 2026-10-11; OPTIONAL FOR PILOT)

**Goal:** Trigger common Food-Fixer actions without hunting through OBS menus.

- [ ] **Do not purchase a physical Stream Deck** before baseline recording works and the control need is demonstrated.
- [ ] Try **Elgato Stream Deck Mobile**, which presently includes **six free programmable keys**, on existing iPhone.
- [ ] Install compatible **Stream Deck desktop software** on Acer; mobile app cannot drive desktop actions on its own.
- [ ] Pair iPhone with Acer by documented Wi-Fi setup/manual process; if trying Windows USB mode, check current Stream Deck version and Apple Devices requirement.
- [ ] Configure **one key first**, not six: trigger the original Food-Fixer order-received WAV via OBS.
- [ ] Verify the cue can be heard on the recording, only once, and without severe lag.
- [ ] Add remaining concept keys as useful: **ON SHIFT, OFF SHIFT, NEW ORDER, DELIVERED, CORP ALERT, MUTE MIC**.
- [ ] Test simple OBS scene/graphic toggles and microphone mute functionality.
- [ ] Verify Stream Deck app plus Cyberpunk plus OBS do not cause unacceptable performance loss.
- [ ] Keep OBS keyboard hotkeys as the free, lowest-complexity fallback.
- [ ] Do **not** let a DELIVERED button automatically credit money: payroll remains its own verified step after successful delivery.
- [ ] Skip profile cosmetics, macros, bought icons, and hardware until the core show is reliable.

**PASS:** One free phone button can reliably trigger one meaningful Food-Fixer action **or** the hotkey alternative works. Neither is required to edit the pilot.
